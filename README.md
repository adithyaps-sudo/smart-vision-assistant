## Overview

Smart Vision Assistant turns a standard webcam into an interactive AI interface. The system detects objects in the live camera feed, tracks the user's hand to control a virtual pointer, and lets the user select an object with a simple gesture. The user can then ask a question about the selected object, and the answer is generated by a Groq-hosted LLM.

---

## Features

- **Real-Time Object Detection:** Fast, accurate detection using YOLOv8.
- **Hand Gesture Recognition:** Hand landmark tracking using MediaPipe.
- **Gesture-Based Object Selection:** Select detected objects with a 2-finger gesture.
- **Virtual Pointer Control:** Move an on-screen pointer using your index finger.
- **AI-Powered Question Answering:** Context-aware responses from a Groq LLM about the selected object.
- **Live Camera Interface:** Real-time video feed with overlaid detections and pointer.

---

## How It Works

1. Capture live video from the webcam.
2. Detect objects in each frame using YOLOv8.
3. Track hand landmarks using MediaPipe.
4. Map finger gestures to a virtual pointer.
5. Select an object using the 2-finger gesture.
6. Send the user's question, along with the selected object's context, to the Groq LLM API.
7. Display the AI-generated response.

## Installation

### Prerequisites

- Python 3.8 or higher
- A working webcam
- A Groq API key ([get one here](https://console.groq.com/))

### Steps

1. **Clone the repository**

```bash
   git clone https://github.com/adithyaps-sudo/Smart-Vision-Assistant.git
   cd Smart-Vision-Assistant
```

2. **(Recommended) Create a virtual environment**

```bash
   python -m venv venv
   source venv/bin/activate      # On Windows: venv\Scripts\activate
```

3. **Install dependencies**

```bash
   pip install -r requirements.txt
```

   Or install the libraries manually:

```bash
   pip install opencv-python mediapipe ultralytics numpy groq
```

## Configuration

### Model files

Make sure the following files are in the project root directory:

- `yolov8n.pt`
- `hand_landmarker.task`

### API key

Set your Groq API key as an environment variable. Do not hard-code it in the source code or commit it to GitHub.

```bash
# Linux / macOS
export GROQ_API_KEY="your_api_key_here"

# Windows (PowerShell)
$env:GROQ_API_KEY="your_api_key_here"
```

## Usage

1. Run the application:

```bash
   python main.py
```

2. Point your index finger to move the on-screen pointer.
3. Hover over a detected object and raise two fingers to select it.
4. Press `Q` to ask a question about the selected object.
5. Read the AI-generated response on screen.
6. Press `ESC` to exit.

## Troubleshooting

| Issue | Possible Solution |
|-------|-------------------|
| Camera not detected | Close other apps using the webcam, or change the camera index in `cv2.VideoCapture()` |
| Model file not found | Confirm `yolov8n.pt` and `hand_landmarker.task` are in the project root |
| LLM response fails | Check that `GROQ_API_KEY` is set and your internet connection is working |
| Low frame rate | Use a smaller YOLOv8 model, lower the camera resolution, or run on a GPU |
| Gestures not recognized | Improve lighting and keep your hand fully inside the camera frame |
